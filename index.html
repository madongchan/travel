        📶 eSIM

        1. eSIM은 폰 안에 넣는 디지털 유심이에요. 한국 유심은 그대로 두고 데이터만 eSIM으로 써요.
        2. 트립닷컴에서 홍콩 3일(매일 2GB, 3,386원)을 원화로 사서, 출발 전에 QR로 설치만 해둬요.
        3. 홍콩 도착 후 데이터 회선을 eSIM으로 바꾸고, 한국 회선의 데이터 로밍은 꺼요.
        자세히

        원리

        폰에 회선이 두 개가 돼요. 한국 번호는 문자 인증·전화 수신용으로 켜두고, 인터넷은 홍콩 현지 통신망을 쓰는 eSIM으로만 나가요. 그래서 로밍 요금 폭탄이 없어요.

        내 폰이 되나요?

        • 아이폰: XS·XR 이후 모델. 한국에서 산 아이폰은 OK.
        • 갤럭시: 국가·모델마다 달라요. 설정 → 연결 → SIM 관리자에 ‘eSIM 추가’ 메뉴가 있으면 돼요.

        아이폰

        1. 설정 → 셀룰러 → eSIM 추가 → QR 스캔
        2. 회선 이름 정하기, 기본 회선은 한국 번호
        3. (홍콩 도착 후) 셀룰러 데이터 → eSIM 회선
        4. eSIM 회선의 ‘데이터 로밍’ 켜기
        5. 한국 회선의 ‘데이터 로밍’ 끄기

        갤럭시

        1. 설정 → 연결 → SIM 관리자 → eSIM 추가 → QR 스캔
        2. (홍콩 도착 후) SIM 관리자 → 모바일 데이터 → eSIM
        3. 설정 → 연결 → 모바일 네트워크 → 데이터 로밍 켜기
        4. 한국 SIM은 데이터 로밍 꺼진 상태 확인

        어떤 상품을 고를까

        • 3일, 매일 1–2GB 또는 무제한(속도 제한형)이면 충분해요. 지도·메신저·검색 정도예요.
        • 추천: 트립닷컴 매일 2GB 3,386원(핫스팟 가능, 후기 3,488개). 홍콩 현지망(CSL)을 원하면 유심사 6,300원.
        • 트립닷컴 상품은 매일 홍콩시간 00:00에 한도 초기화, 처음 연결한 때부터 24시간 단위. 이미 홍콩에 있으면 쓰기 직전에 설치하라고 안내해요.
        • QR은 한 번만 스캔돼요. 설치 전에 캡처해 두고, 지우지 마세요.
